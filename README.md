# Hot 100 复习台

一个纯前端的 LeetCode Hot 100 做题与复习记录网站。

## 本地使用

用本地静态服务器打开 `dist` 目录，然后在页面右上角的“数据”中导入旧版 JSON 记录。

## 复习规则

- 前五次之间沿用固定节奏：1、4、10、21 天。
- 第 1 至第 5 次只记录完成日期。
- 第 6 次及以后，根据本次掌握程度决定下次复习：熟练写出 5 天、思路了解 3 天、完全没思路 1 天。
- 完成次数没有上限，每次记录后都会自动出现下一次。

## 数据安全

进度默认保存在当前浏览器的 localStorage 中。请定期使用“导出备份”。`private-data/` 只用于本机兼容性测试，不会进入 Git。
